# PFLB TEAM 3

## О проекте
Проект разработан в рамках дипломного задания по автоматизации тестирования.

Цель проекта — реализовать набор автотестов для учебного полигона **PFLB Test-API** и продемонстрировать полный цикл автоматизации: запуск тестов, проверку результатов, формирование отчетов и интеграцию c CI/CD

## Стек
| Компонент | Технология | Описание |
|-----------|------------|----------|
| Язык | Java | Основной язык проекта |
| Сборка | Maven | Управление зависимостями и запуском тестов |
| Тестирование | JUnit5 | Базовый тестовый фреймворк |
| UI | Selenide | UI-автотесты |
| API | RestAssured | API-автотесты |
| БД | PostgreSQL, JDBC | Проверка данных в базе |
| Логи | Log4j2 | Логирование выполнения |
| Отчеты | Allure | Генерация отчетов |
| CI/CD | GitHub Actions | Автозапуск в pipeline |
| CI/CD | Jenkins | Сборка проекта и запуск тестов в Jenkins pipeline |

## Возможности проекта
* UI-тесты для проверки основных сценариев
* API-тесты для работы с сущностями Users, Cars и Houses
* Проверка данных в базе после выполнения операций
* Формирование Allure-отчета
* Автоматический запуск тестов через GitHub Actions
* Сборка проекта и запуск тестов через Jenkins

## Требования к окружению
#### Для запуска проекта нужны:
* Java 17 
* Maven 
* PostgreSQL
* Доступ к учебному стенду PFLB Test-API 
* Браузер для UI-тестов 
* Доступ к GitHub Actions при запуске в CI

## Запуск локально
#### Запуск тестов
```bash
mvn clean test
```
#### Генерация allure-отчета
```bash
mvn allure:serve
```
